# Network Diagnostics CLI

A simple Python command-line tool for basic network diagnostics.

## Overview

This project resolves a hostname into its corresponding IP address using Python's socket library.

The goal of this project is to build practical understanding of networking concepts while improving Python programming skills.

## Features

- Hostname input from the user
- DNS resolution
- IP address display
- Error handling for invalid hostnames

## Technologies Used

- Python
- Socket module
- DNS fundamentals
